Descripción
Proyecto académico desarrollado en Java para la asignatura Programación Avanzada I, utilizando Apache NetBeans, 
programación orientada a objetos y una estructura basada en el patrón Modelo-Vista-Controlador (MVC).

Objetivo
Desarrollar una aplicación de escritorio que permita ingresar y visualizar información básica de contactos mediante una 
interfaz gráfica.

Tecnologías utilizadas
Java
Apache NetBeans
Java Swing
Apache Maven
Git y GitHub

Funcionamiento
La aplicación permite ingresar el nombre y número telefónico de un contacto. 
Al presionar el botón Guardar Contacto, se crea un objeto con los datos ingresados y se muestra un mensaje de confirmación 
en pantalla.

Estructura del proyecto
Modelo: clase Contacto.java, que contiene los datos del contacto.
Vista: clase VentanaContacto.java, que contiene la interfaz gráfica.
Controlador: clase MainContacto.java, que permite iniciar la aplicación.
